# PWA Plano Meia Maratona RUN/WALK/RUN

Arquivos principais:
1. index.html
2. manifest.webmanifest
3. sw.js
4. icons/icon-192.png
5. icons/icon-512.png

Como usar:
1. Hospede a pasta em um serviço com HTTPS.
2. Abra o endereço no navegador do celular.
3. No Chrome Android, toque em Instalar aplicativo ou Adicionar à tela inicial.
4. No Safari iPhone, toque em Compartilhar e depois Adicionar à Tela de Início.

Observação importante:
Abrir o index.html diretamente como arquivo local pode funcionar para visualizar, mas normalmente não permite instalar como PWA, porque service worker exige HTTPS ou localhost.
